Сессия 2.
Включение двух светодиодов из разных выходов, мигание с периодичностью.
Функциональная обертка управления пинами на python.

Устройства:
    Чип ft232h (Future Technologies / High Speed)
    Макетная плата
    Резистор 220 Ом (2шт)
    Светодиод (2шт)
    Шнур usb
    Соединительные провода

Схема:
AD1 ──[ 220 Ом ]── Анод(LED1) ── Катод(LED1) ──┐
                                               │
AD3 ──[ 220 Ом ]── Анод(LED2) ── Катод(LED2) ──┤
                                               │
GND ───────────────────────────────────────────┘

    FT232H (CJMCU)
    ┌─────────────┐
    │             │
    │  AD1 ●──────┼───────[ 220 Ом ]────── Анод(LED1) ── Катод(LED1) ──┐
    │             │                                                    │
    │  AD3 ●──────┼───────[ 220 Ом ]────── Анод(LED2) ── Катод(LED2) ──┤
    │             │                                                    │
    │  GND ●──────┼────────────────────────────────────────────────────┘
    │             │
    └─────────────┘
