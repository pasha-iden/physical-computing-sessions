Сессия 1.
Настройка устройства, пакетов и драйверов.
Сборка и подключение первой схемы.
Включение одного светодиода, постоянное свечение.

Устройства:
    Чип ft232h (Future Technologies / High Speed)
    Макетная плата
    Резистор 220 Ом
    Светодиод
    Шнур usb
    Соединительные провода

Схема:
AD0 ──[220 Ом]── Анод (длинная ножка) ── Катод (короткая ножка) ── GND

        FT232H (CJMCU)
        ┌─────────────┐
        │             │
        │  AD0 ●──────┼──────────┐
        │             │          │
        │  GND ●──────┼───────┐  │
        │             │       │  │
        └─────────────┘       │  │
                              │  │   ┌──────────┐
                              │  └───┤ Резистор │
                              │      │  220 Ом  │
                              │      └────┬─────┘
                              │           │
                              │      ┌────┴─────┐
                              │      │  Анод    │
                              │      │  (LED)   │
                              │      │  Катод   │
                              │      └────┬─────┘
                              └───────────┘

Используется модуль объект GpioController модуля pyftdi.gpio .
Режим GPIO: General Purpose Input/Output — «порт общего назначения».
Это пин, которым можно управлять из кода:
    Output — подать HIGH (3.3V) или LOW (0V).
    Input — прочитать, что на нём сейчас (HIGH или LOW).
Минус: чип не может писать и читать сигналы непосредсвенно сам,
а только передает данные между ПО и схемой.
Это решается режимом MPSSE, о чем будет в 3й сессии.
